<div slot="cli">

```sh
cargo install chartlet --version 0.1.0-alpha.5
```

To build from a clone of the repository instead, run `cargo install --path .`.

</div>
<div slot="astro">

```sh
npm install @casoon/chartlet@alpha
```

The package carries the renderer as WebAssembly; it needs no Rust toolchain. To render with an
installed CLI instead, set `CHARTLET_BIN` to its path.

</div>
<div slot="rust">

```sh
cargo add chartlet@0.1.0-alpha.5
```

</div>
</Tabs>

<Callout type="caution">
  While chartlet is in alpha, name the version explicitly. On npm, use the `alpha` tag.
</Callout>

## Requirements

| Package | Requirement |
| --- | --- |
| CLI and crate | Rust 1.88 or newer |
| `@casoon/chartlet` | Node.js 22.12 or newer; Astro 6 or newer for the component |
