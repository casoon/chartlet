<div slot="cli">

```sh
cargo install chartlet
```

To build from a clone of the repository instead, run `cargo install --path .`.

</div>
<div slot="astro">

```sh
npm install @casoon/chartlet
```

The package carries the renderer as WebAssembly; it needs no Rust toolchain. To render with an
installed CLI instead, set `CHARTLET_BIN` to its path.

</div>
<div slot="rust">

```sh
cargo add chartlet
```

</div>
</Tabs>

<Callout type="caution">
  Until 1.0, a minor release (0.2, 0.3, …) may change the specification. Pin the minor version
  (`chartlet = "0.12"`, `"@casoon/chartlet": "~0.12.2"`) to take only patch releases.
</Callout>

## Requirements

| Package | Requirement |
| --- | --- |
| CLI and crate | Rust 1.88 or newer |
| `@casoon/chartlet` | Node.js 22.12 or newer; Astro 6 or newer for the component |
